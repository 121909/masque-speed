    如何理解结果

    延迟 = TTFB
    经隧道发起请求到收到首字节的时间，并非 ICMP Ping。
    速度 = Mbps
    每秒兆比特，约 8 Mbps = 1 MB/s。只有延迟达标才会继续下载测速。
    TCP 与 UDP
    指隧道外层传输：TCP 使用 HTTP/2，UDP 使用 QUIC。“TCP + UDP”模式下任一传输达标，该节点即计为达标；同一节点只计一次。
    目标与结束
    默认串行测试。达到总目标或所有地区目标即停止；候选耗尽与手动停止会明确标记，不代表已达到目标。
